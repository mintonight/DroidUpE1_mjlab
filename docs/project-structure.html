奖励函数：目标怎么算

EnvConfig 决定启用哪些奖励及其权重；mdp/rewards.py实现数学计算。

最重要的区别： Reward 是环境给策略的任务分数；PPO 的 value loss、surrogate loss、entropy loss 是优化器内部指标。奖励函数不放在 RLConfig 里，loss 也不放在 mdp/rewards.py 里。

Mimic 核心文件分别做什么

src/tasks/mimic/config/e1_21dof/tracking_env_cfg.py — EnvConfig
  • 组装 actor/critic 观测、21 维关节位置动作和动作参考 command。
  • 配置 push、质量/惯量、COM、PD、摩擦、编码器偏差等 domain randomization。
  • 列出奖励项、权重、终止条件、场景、传感器、仿真步长和 viewer。
  • has_state_estimation=False 会从 actor 删除 anchor position 与 base linear velocity。
  • play=True 会关闭噪声、延迟、随机化，并从动作第 0 帧开始。
src/tasks/mimic/config/e1_21dof/rl_cfg.py — RLConfig
定义 30,000 iterations、24 steps/env、每 500 次保存、actor/critic MLP（512→256→128）及 PPO 的学习率、gamma、lambda、KL、entropy 等参数。
src/tasks/mimic/mdp/commands.py — 动作参考与采样
MotionLoader 读取 NPZ；MotionCommand 按 time step 提供目标关节、身体位置/旋转/速度，处理随机起点、reset、pose 扰动、自适应采样和 ghost model。当前 command 是 21 维目标关节角 + 21 维目标关节速度，共 42 维。
src/tasks/mimic/mdp/observations.py — 自定义观测
计算目标 anchor 在机器人坐标系的位置/朝向，以及机器人各身体相对 anchor 的位置和 6D 朝向表示。通用关节、IMU、last action 观测来自 mjlab 内置 MDP 函数。
src/tasks/mimic/mdp/rewards.py — 奖励公式
实现参考 root/body 与机器人之间的位置、旋转、线速度、角速度指数奖励，以及自碰撞惩罚。是否启用和权重仍由 EnvConfig 决定。
src/tasks/mimic/mdp/terminations.py — 提前终止
当躯干高度、姿态或手脚高度与参考动作相差过大时结束 episode；这比扣分更强，会直接 reset 环境。
src/tasks/mimic/mdp/metrics.py — 只记录、不直接优化
计算 MPKPE、root-relative MPKPE、关节速度误差和末端位置/旋转误差，用于 TensorBoard 诊断。
src/tasks/mimic/rl/runner.py — checkpoint 与 ONNX
扩展标准 RSL-RL runner。保存 model_N.pt 时同步导出 ONNX，并把本次动作的 joint/body 参考张量和部署 metadata 一起打包。
src/tasks/mimic/config/e1_21dof/__init__.py — 任务注册
注册有状态和 No-State 两个 task ID，告诉训练脚本该加载哪个 EnvConfig、RLConfig 和 Runner。

当前 Mimic 奖励函数放在哪里

下表中的“配置位置”负责权重和参数；“实现函数”负责计算每个环境的 reward tensor。

EnvConfig 名称权重实现函数（mdp/rewards.py）作用
motion_global_root_pos+0.5motion_global_anchor_position_error_exp跟踪 torso 的世界坐标位置。
motion_global_root_ori+1.0motion_global_anchor_orientation_error_exp跟踪 torso 的世界朝向；转圈是否跟上主要看它。
motion_body_pos+1.0motion_relative_body_position_error_exp跟踪各身体相对 root 的位置，关注姿态形状。
motion_body_ori+1.0motion_relative_body_orientation_error_exp跟踪各身体相对朝向。
motion_body_lin_vel+1.0motion_global_body_linear_velocity_error_exp跟踪身体世界线速度。
motion_body_ang_vel+1.0motion_global_body_angular_velocity_error_exp用 std=2.0 专门跟踪 torso 世界角速度，强化转向。
action_rate_l2−0.1mjlab.mdp.action_rate_l2抑制相邻动作跳变。
joint_limit−10.0mjlab.mdp.joint_pos_limits惩罚接近或越过关节软限位。
self_collisions−10.0self_collision_cost惩罚超过 10 N 的自碰撞。
为什么 loss 很低仍可能不会转？ PPO loss 只说明更新稳定、critic 拟合得不错；真正的行为方向由奖励与观测共同决定。若相对身体奖励很容易拿，而目标 yaw 信息不足，策略会收敛到“动作像但不转身”。

另一条任务线：AMP

src/tasks/amp/config/e1_21dof/env_cfg.py

速度指令 locomotion 的 EnvConfig。奖励更多：线速度、yaw 速度、站立、步态、脚滑、触地、脚间距、能耗、接触等。

src/tasks/amp/config/e1_21dof/rl_cfg.py

除 PPO 外，还配置 AMP motion files、discriminator、replay buffer、gradient penalty 和镜像增强。

src/tasks/amp/mdp/rewards.py

实现 AMP 任务奖励。它与 Mimic 的 mdp/rewards.py 完全分开，修改时先确认当前 task ID。

src/tasks/amp/rl/

包含自定义 AmpPPO、判别器、motion loader、normalizer 与 replay buffer。
